# SaaS SEO & GEO Optimizer Skill

Full-lifecycle **SEO**, **GEO (Generative Engine Optimization)**, and **AEO** growth skill for AI tool sites, SaaS products, and indie web apps.

## What It Synthesizes

- **23-Chapter SaaS SEO Playbook** ([JeffLi1993/saas-seo-playbook](https://github.com/JeffLi1993/saas-seo-playbook)): ICP mapping, DR 30-50 competitor reverse-engineering, Topic Map & Page Owner architecture, URL hierarchy, Tool/Blog/Alternatives/Comparison templates, 3-way internal linking, backlink pipelines, pSEO, i18n, and GEO.
- **5D Low-Competition Keyword Opportunity Scoring**: Prioritizing `Quick Wins`, `Strategic`, and `Avoid for Now` clusters without fabricating third-party search volume or KD metrics.
- **Knowledge Base Rules (`SEO-001` to `SEO-019`) & Deep Audit Protocol**: Evidence-tiered (`CONFIRMED` / `SYNTHESIS` / `HEURISTIC`) codebase diagnostics, Brand SERP #1 defense, `llms.txt` / `sameAs` entity alignment, and `[CHANGE] / [EVIDENCE] / [RESULT] / [NEXT]` engineering receipts.
